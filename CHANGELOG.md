# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of Vaultic PHP SDK
- `VaulticClient` main client class
- `Prompts` resource for managing prompts
- `Projects` resource for managing projects
- HTTP Client with full error handling
- Exception classes for all HTTP error codes
- Helper classes:
  - `VariableReplacer` for replacing variables in prompts
  - `VariableExtractor` for extracting variable names
  - `VariableValidator` for validating required variables
- Comprehensive test suite
- Full documentation and examples
